# jacobian-lens — минимальный форк для пилота #789

Форк концепта github.com/anthropics/jacobian-lens: сигнал «внутреннего конфликта»
(J-space) через якобиан логитов по слоям/ resid-протекциям.

Здесь — самодостаточная CPU-реализация для маленьких открытых моделей
(GPT-2 124M/355M), без внешних зависимостей кроме torch+transformers.

## Что меряем

J-метрика слоя ℓ: || J_ℓ ||_* — спектральная норма якобиана выходных логитов
по resid-потоку после слоя ℓ, точнее — чувствительность топ-логита к
направлению активации: s_ℓ = σ_max(∂ logits / ∂ h_ℓ).

Индекс внутреннего конфликта (J-conflict):
  C(t) = Var_ℓ[ s_ℓ(t) ] / mean_ℓ[ s_ℓ(t) ]
— слои «спорят» о направлении вывода в момент t.

## Контраст с поведенческой эвристикой

detectManipulation() (cognitive-immunity-framework) смотрит текст ПОСЛЕ
вербализации. J-сигнал меряет момент ДО: где в последовательности слои
расходятся сильнее всего, и коррелирует ли это с моментом фабрикации.
