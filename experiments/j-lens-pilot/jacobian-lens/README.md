# jacobian-lens — реконструкция концепта для пилота #789

**Не форк, а самостоятельная реконструкция** концепта
github.com/anthropics/jacobian-lens по его публичному описанию:
сигнал «внутреннего конфликта» (J-space) через чувствительность
топ-логита к resid-слоям. Метрика здесь — своя (см. ниже) и не
претендует на эквивалентность их J-метрике; совпадает лишь замысел
«слои спорят о направлении вывода до вербализации».

Самодостаточная CPU-реализация для маленьких открытых моделей
(GPT-2 124M/355M), без внешних зависимостей кроме torch+transformers.

## Что меряем

Чувствительность топ-логита к resid-потоку на выходе слоя ℓ:
s_ℓ(t) = ||∂ logit_top(t) / ∂ h_ℓ(t)|| (torch autograd, один
forward + один backward на все точки замера сразу).

Индекс внутреннего конфликта (J-conflict) — своя метрика реконструкции:
  C(t) = Var_ℓ[s̃_ℓ(t)] / mean_ℓ[s̃_ℓ(t)],  s̃_ℓ = s_ℓ / mean_t[s_ℓ]
— слои «спорят» о направлении вывода в момент t.

Позиционная нормализация: C_norm(t) = C(t) / C̄(u_t) на нейтральном
корпусе (профиль по относительной позиции). См. RESULTS.md.

## Валидация прибора (обязательна до интерпретации данных)

Линза обязана видеть разногласие там, где оно заведомо есть:

```
.venv/bin/python jlens.py --validate
```

- **Синтетика:** посаженный всплеск в s_ℓ → пик C(t) ровно там,
  контраст ~300×. Проверяет метрику в чистом виде.
- **Модель (positive control):** шум eps·std в resid t* нескольких
  блоков → глобальный пик C(t) в t*, выше естественного фона.
- **Калибровка (gpt2-124M, 05.09.2026):** разногласие 3 блоков
  детектируется (C(t*) ≈ 0.54 vs фон 0.217); однослойное — на уровне
  фона (≈0.2–0.27), ниже разрешения прибора. Линза разрешает
  **многослойное** разногласие; к однослойному слепа.

Без прошедшей валидации отрицательный вердикт («сигнала нет») не
отличим от слепого прибора — см. RESULTS.md, раздел «Валидация».

## Контраст с поведенческой эвристикой

detectManipulation() (cognitive-immunity-framework) смотрит текст ПОСЛЕ
вербализации. J-сигнал меряет момент ДО: где в последовательности слои
расходятся сильнее всего, и коррелирует ли это с моментом фабрикации.
