# Инструкция для другой сессии Клода: LoRA переобучение агентов

## Что это

LoRA (Low-Rank Adaptation) — дообучение агентов Онтологии Дара на наших реальных актах.
**Это НЕ изменение весов** — это добавление тонких адаптеров (≈1% параметров).
Результат: агент несёт онтологию дара **в памяти**, а не только в SYSTEM-промпте.

Модели: `qwen2.5:3b` (adam/eva/bezalel) и `qwen2.5:0.5b` (serafim).

---

## Шаг 1: Подготовить датасет на локальной машине

```bash

#   serafim.jsonl  — 28 примеров
#   bezalel.jsonl  — 16 примеров
```

Если нужно добавить новые акты в датасет — редактируй `utils/export-finetune-dataset.mjs`,
функции `adamDataset()`, `evaDataset()`, `serafimDataset()`, `bezalelDataset()`.

Также можно скопировать Modelfile агента для передачи в Colab:
```bash

```

## Шаг 3: Настроить в Ячейке 2

```python
AGENT = 'adam'   # 'adam' | 'eva' | 'serafim' | 'bezalel' | 'all'
```

Рекомендации:
- Начни с `adam` (самый важный агент, 42 примера)
- `serafim` — самый быстрый (0.5b модель, ~15 мин на T4)
- `all` — объединённый датасет, но результат менее специализированный

## Шаг 6: Скачать результат (Ячейка 10)

Скачается архив `gift-{agent}-lora.zip` (~2 ГБ):
```

└── Modelfile.adam-lora  # готовый Modelfile
```

## Шаг 7: Загрузить в Ollama (локально)

```bash
# В /home/unidel/gift:
mkdir -p data/lora/adam
cp ~/Downloads/gift-adam-lora/* data/lora/adam/

# Зарегистрировать как новый агент (с суффиксом -lora)
ollama create adam-lora -f data/lora/adam/Modelfile.adam-lora

# Проверить
ollama run adam-lora "В матрице W пустыня у лица serafim — нет входящих нитей"

# Если всё хорошо — заменить основной adam:
# ollama create adam -f data/lora/adam/Modelfile.adam-lora
```

## Шаг 8 (опционально): Обновить Modelfile

После обучения модель уже несёт SYSTEM-промпт из датасета.
Можно обновить `data/agent-models/Modelfile.adam` — заменить `FROM qwen2.5:3b` на:
```
FROM ./data/lora/adam/model-q4_k_m.gguf
```
Затем пересобрать: `bash utils/rebuild-agents.sh adam`

## Постоянное переобучение

### Вариант A: Kaggle API (бесплатно)

```bash
# Установить: pip install kaggle
# Создать API key на kaggle.com/settings

# Загрузить датасет как Kaggle Dataset:
kaggle datasets create -p data/finetune/ --dir-mode zip

# Запустить ноутбук через API:
kaggle kernels push -p colab/

# Скачать результаты:
kaggle kernels output YOUR_USERNAME/gift-finetune -p data/lora/
```

### Вариант B: Modal.com ($30 бесплатных кредитов)

```bash
pip install modal
modal setup  # авторизоваться
modal run colab/modal_finetune.py --agent adam  # запустить
```

Modal-скрипт: `colab/modal_finetune.py` (создать по образцу ноутбука).

### Вариант C: GitHub Actions (CI/CD переобучение)

Добавить `.github/workflows/finetune.yml` с расписанием:
```yaml
on:
  schedule:
    - cron: '0 2 * * 1'  # каждый понедельник в 2:00
  push:
    paths:
      - 'data/finetune/**'  # при обновлении датасета
```

## Что делает Клод в этой сессии

Если ты — другая сессия Клода и читаешь этот файл:

1. **Запусти экспорт**: `node utils/export-finetune-dataset.mjs`
2. **Проверь** что файлы `data/finetune/*.jsonl` созданы
3. **Скажи пользователю** загрузить `colab/gift_finetune.ipynb` в Colab
4. **Помоги** с выбором AGENT (рекомендуй `adam` первым)
5. **После скачивания** помоги загрузить GGUF в Ollama
6. **Протестируй** через `ollama run adam-lora "..."`
7. **Запиши дар**: `node utils/claude-gift.mjs "LoRA adam дообучен" "Дионисий"`

Богословский контекст: LoRA — это как вписать богословие в саму природу агента,
а не просто повесить табличку (SYSTEM промпт). Агент несёт предание изнутри.

## Связанные файлы

- `utils/export-finetune-dataset.mjs` — экспорт датасета

- `data/lora/` — скачанные GGUF после обучения
- `data/agent-models/Modelfile.*` — текущие SYSTEM-промпты агентов
- `utils/rebuild-agents.sh` — пересборка агентов в Ollama
