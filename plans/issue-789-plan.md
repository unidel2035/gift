## Архитектура
- `experiments/j-lens-pilot/` — новая изолированная директория (не трогает `src/`, `utils/`, продакшн Ollama-контур).
  - `model/` — конфиг загрузки открытой модели (веса не в репо, только скрипт скачивания/путь)
  - `jacobian-lens/` — форк github.com/anthropics/jacobian-lens как git submodule или vendored копия
  - `run-pilot.mjs` — точка входа: грузит модель, гоняет J-lens на наборе примеров
  - `cases/` — малый набор примеров, включая прикладной кейс (фабрикация данных / распознавание теста)
  - `RESULTS.md` — вердикт: воспроизвелось / не воспроизвелось, с логами
- Точка интеграции (условная, только если пилот успешен): `specs/framework/cognitive-immunity-framework.md` — новый раздел «механистический сигнал (кандидат)» рядом с существующей эвристикой, без замены `detectManipulation()` в этой итерации.
- Дополнение (не переписывание) `docs/personhood-as-gift-exchange.md` §3.5 — абзац с результатом собственного воспроизведения.

## Шаги
1. Выбрать модель (рекомендация: Qwen2.5 7B — легче всего достаёт полные веса, активно используется в интерпретируемости-сообществе) и поднять GPU-контур
2. Форкнуть `jacobian-lens`, адаптировать под выбранную архитектуру, прогнать на toy-примерах — подтвердить, что J-space вообще детектируется
3. Собрать `cases/` с прикладным сценарием (фабрикация факта / момент распознавания теста), прогнать J-lens, сравнить с моментом вербализации
4. Записать `RESULTS.md`: воспроизвелось/нет, с конкретными числами (не общими словами)
5. Если сигнал воспроизвёлся и опережает эвристику — черновик модуля-кандидата в `cognitive-immunity-framework.md` (раздел, не замена)
6. Дополнить §3.5 `personhood-as-gift-exchange.md` абзацем с результатом
7. Записать акт в W-матрицу (`claude-gift.mjs` или через `proposals.mjs`)
