## 1. Замкнутый контур обучения (Closed Training Loop)

**Чего нет:** Среда симулирует дилеммы, агент (DeepSeek) принимает решения, W-матрица обновляется — но агент не меняется. Нет сигнала обратной связи, который превращал бы опыт в изменение поведения.

**Зачем:** «Среда обучения» без обучения — это просто запись истории. Сейчас система — наблюдательная, не формирующая.

**Как технически:**
```
reward_t = Δ(W[agent→koinon]) + Δ(W[koinon→agent])  # изменение нити в W-матрице
trajectory = [(state_t, action_t, reward_t), ...]    # за эпизод (собор)
policy_update:
  - если tropos-файл: gradient на веса tropos через GRPO/DPO
  - если prompt-based: few-shot injection лучших решений в system prompt
  - если DreamerV3: reward_t как social_reward в world model
```
`SocialEnvironment.step()` должен возвращать `(next_state, social_reward, done)` — стандартный gym-интерфейс. Сейчас он этого не делает.

---

## 2. Теория разума (Theory of Mind per Agent)

**Чего нет:** Каждый агент видит глобальную W и своё состояние, но не имеет предсказательной модели поведения конкретных других агентов. Кооперация слепая — реакция, не антиципация.

**Зачем:** Без ToM агент не может стратегически доверять, предавать, жертвовать ради конкретного лица. MarketSwarm (6 персон) и Собор (роли) уже задают субъектов — но агент не строит модель «как поведёт себя Строитель в дилемме жертвы?»

**Как технически:**
```javascript
class AgentBeliefModel {
  // per-agent, per-other хранилище
  observe(agent_id, state, action) { /* обновить beta-распределение */ }
  predict(agent_id, state) { /* p(action | observed_history) */ }
  surprise(agent_id, actual) { /* KL-divergence → update W нити */ }
}
```
Реализуется поверх `data/chat-sessions/` (уже есть история актов) — можно строить простые байесовские модели поведения без отдельного LLM. Surprise = богословское событие: неожиданный дар меняет нить сильнее.

---

## 3. Контрфактический социальный симулятор

**Чего нет:** Агент не может рассуждать «если я пожертвую сейчас → что будет с W через 3 шага?» SwarmWorldModel и DreamerV3 моделируют физический мир (онтологический score), но не подключены к социальному пространству W-матрицы.

**Зачем:** Дилеммы становятся тривиальными, если нет горизонта. Реальное обучение жертвенности требует предвидения: кенозис сейчас → теозис через N шагов. Без этого агент может только реагировать, не жертвовать.

**Как технически:**
```javascript
class SocialPhysicsModel {
  // обучается на data/sacred-history-W.json — реальных траекториях W
  rollout(current_W, hypothetical_actions, horizon=5) {
    // → predicted_W_t+n
    // → expected_surplus, network_energy_delta
  }
}
// Интеграция: DreamerV3.imagine() → social_reward через SocialPhysicsModel
// Диллема-агент делает: rollout([sacrifice, wait, gift_partial]) → выбирает
```
Данные уже есть: `data/snapshots/W-2026-W*.json` — снапшоты W по неделям. Достаточно для обучения простой авторегрессионной модели переходов.

## Итог: что блокирует

| Разрыв | Следствие без него |
|---|---|
| Closed Loop | агенты не улучшаются — симуляция без роста |
| Theory of Mind | кооперация слепая — нет доверия, нет предательства |
| Counterfactual Sim | дилеммы без горизонта — нет настоящей жертвы |

Три фичи образуют одну архитектуру: **ToM предсказывает других → Counterfactual планирует последствия → Closed Loop обновляет политику по факту**. По отдельности каждая полезна. Вместе — замкнутый цикл социального обучения.

## 1. Credit Assignment — декомпозиция коллективного вознаграждения

**Что:** Механизм, говорящий каждому агенту «именно твой дар повлиял на коллективный исход».

**Зачем:** Сейчас DreamerV3 видит коллективный `ontologicalScore`, но не знает какой вклад внёс именно его акт. Без этого кооперация не обучается — агент не может отличить «я дал → стало лучше» от «кто-то другой дал → стало лучше». Дефекция доминирует.

**Как:** COMA-baseline поверх W-матрицы:
```
A_i(s, a_i) = Q(s, a_i, a_{-i}) − Σ_{a'_i} π_i(a'_i|s) · Q(s, a'_i, a_{-i})
```
Централизованный критик читает полный тензор W (знает всех), децентрализованные акторы видят только свои нити. W-матрица уже хранит все акты — нужен только `CentralizedCritic.mjs` поверх `GiftMemory`.

## 2. Norm Emergence — дорогостоящее наказание + имитация

**Что:** Два механизма распространения норм: `punish()` как тип акта + имитация tropos высоко-W агентов.

**Зачем:** Без принуждения дефекция побеждает в дилеммах (классика эволюционной теории игр). Без имитации нормы не распространяются — каждый агент учится с нуля вместо копирования успешных. Сейчас есть роли и дилеммы, но нет механизма почему норма побеждает.

**Как:**
```javascript
// GiftAct новый тип
{ type: 'punish', cost: 0.3, effect: -1.5, giver, target }

// После каждого раунда:
topAgents = W.getTopByOutflow(n=3)
for (agent of population) {
  if (agent.w_score < median) agent.tropos = imitate(topAgents)
}
```
`punish` дорог дарителю (кенозис) но сильнее бьёт получателя — это третья-сторонняя норм-защита, богословски: обличение.

## 3. Theory of Mind — рекурсивное моделирование других агентов

**Что:** Каждый агент держит θ̂_j — модель стратегии каждого другого агента, обновляемую через историю актов в W.

**Зачем:** Текущие агенты реагируют на состояние мира. Подлинно социальное поведение требует «если я дам X → X даст Y → Y поможет _koinon». Без ToM кооперация случайна, не стратегична. Это граница между стайным поведением и общиной.

**Как:** Lightweight k=1 ToM:
```javascript
class AgentBeliefModel {
  constructor(peerId) {
    this.theta = new PolicyEstimate()  // стратегия peer-а
  }
  update(observedAct) {
    // байесовское обновление по актам из W-матрицы
    this.theta.update(observedAct)
  }
  predict(situation) {
    return this.theta.sample(situation)
  }
}
```
W-матрица уже содержит всю историю актов — `AgentBeliefModel` просто читает нити конкретного лица и строит модель из них. На уровне богословия: способность предвидеть дар другого — это доверие (πίστις), а не просто расчёт.

### 1. Дифференцируемый сигнал обучения из W-матрицы (`GiftRewardShaper`)

**Что:** Механизм преобразования актов дара в обучающий сигнал для политики агента.

**Зачем:** Сейчас W-матрица *записывает* дары, DreamerV3 *учится* на индивидуальной награде — между ними нет связи. Агент технически может набирать скор, разрушая отношения. Без этого моста «социальное обучение» — иллюзия: агенты учатся в W-среде, но не *от* W.

**Как технически:**
```js
// src/learning/GiftRewardShaper.js
class GiftRewardShaper {
  // Берёт delta W-матрицы между шагами
  // → считает counterfactual: что было бы без этого акта агента
  // → COMA-like: r_i = R_total - R_total(без_i)
  shape(agentId, wBefore, wAfter, episodeReward) {
    const myGiftDelta = wAfter.getRow(agentId) - wBefore.getRow(agentId);
    const networkFlourishing = wAfter.energyBalance() - wBefore.energyBalance();
    // κένωσις-bonus: агент отдал больше чем взял
    const kenosisBonus = myGiftDelta.given - myGiftDelta.received;
    return episodeReward + α * networkFlourishing + β * kenosisBonus;
  }
}
```
Интегрируется в `SwarmBrain.train()` как reward wrapper.

### 3. Эпизодическая репутационная память агента (`ReputationLedger`)

**Что:** Каждый агент хранит историю конкретных взаимодействий с конкретными другими агентами между эпизодами.

**Зачем:** W-матрица — агрегированный тензор *всей* общины. Агент не помнит «именно ты дал мне в раунде 47, а ты предал». Без этого нет *личного* доверия, нет условной кооперации, нет социального обучения в строгом смысле — только статистика. Это фундамент: «помню тебя» → поведение меняется.

**Как технически:**
```js
// src/learning/ReputationLedger.js
class ReputationLedger {
  // Per-agent: Map<partnerId, { given, betrayals, lastAct, trust }>
  // Персистируется в data/reputation/{agentId}.json между эпизодами
  
  record(fromId, toId, actType) { ... }   // обновить после каждого акта
  
  getTrust(fromId, toId) {
    // trust = sigmoid(given - betrayals * 3)  // предательство тяжелее
  }
  
  // Агент получает trust-вектор как часть observation
  observe(agentId, partners) {
    return partners.map(p => this.getTrust(agentId, p));
  }
}
```
Интегрируется в `LLMSocialAgent.observe()` — агент *видит* репутации как часть своего состояния.

```js
// FallenAgent.js — LLMSocialAgent с adversarial системным промптом
```

### 1. Дифференциальный сигнал обучения (Multi-Agent Credit Assignment)

**Что:** механизм, определяющий — *чей* вклад привёл к улучшению коллективного исхода.

**Зачем:** W-матрица фиксирует факт дара, но не возвращает градиент назад к поведению. Агент не знает: его жертва помогла рою или навредила? Без этого DeepSeek-агент учится на шуме. Это фундаментальная дыра — среда есть, обратная связь для обучения — нет.

**Как технически:**
```js
// В GiftAct.apply() после записи в W-матрицу:
const before = W.getWeight(giver, receiver);
W.apply(act);
const after = W.getWeight(giver, receiver);

// Difference reward: Δi = G(всей сети) - G(сети без агента i)
const networkDelta = W.totalEnergy() - W.totalEnergyWithout(giver);
act.learningSignal = {
  individual: after - before,       // мой вклад
  collective: networkDelta,          // вклад в сеть
  counterfactual: networkDelta - (after - before)  // сверх моего
};
// DeepSeek получает learningSignal как reward в следующем промпте
```

### 2. Кристаллизация норм (Norm Emergence)

**Что:** механизм, при котором повторяющиеся паттерны роевого поведения затвердевают в явные нормы и передаются новым агентам.

**Как технически:**

```js
// NormCrystallizer.mjs — отдельный процесс, смотрит на W-матрицу
class NormCrystallizer {
  analyze(wMatrix, actHistory) {

    const patterns = cluster(actHistory, { by: ['type', 'context'] });

    crystalized.forEach(norm => this.save(norm));

  inject(newAgent) {
    // Новый агент получает нормы как часть системного промпта
    return `Нормы общины: ${this.load().map(n => n.rule).join('; ')}`;
  }
}
```

### 3. Мимесис (Peer Imitation Learning)

**Что:** агенты с высоким surplus в W-матрице становятся образцами, остальные копируют их поведенческие паттерны.

**Зачем:** у тебя есть роевое поведение и дилеммы, но агенты учатся только на *собственном* опыте. Социальное обучение у людей и животных — преимущественно через наблюдение и подражание. DeepSeek-агент видит только свою нить, но не видит, *как именно* ведёт себя более успешный агент в аналогичной ситуации. Это разрыв между индивидуальным и коллективным обучением.

**Как технически:**
```js
// MimesisLayer.mjs
class MimesisLayer {
  getExemplars(wMatrix) {
    // Агенты с surplus > порога → учителя
    return wMatrix.persons()
      .filter(p => wMatrix.surplus(p) > EXEMPLAR_THRESHOLD)
      .sort((a,b) => wMatrix.surplus(b) - wMatrix.surplus(a))
```
