# Gift Protocol — Протокол Дара

**версия:** 1.0
**основание:** православная антропология
**транспорт:** JSON over HTTP
**лицензия:** public domain — сам протокол есть дар

---

## Почему не транзакция

Существующие AI-системы строятся на двух антропологиях:

**Западная:** индивидуальное предпочтение → оптимизация вовлечённости
**Китайская:** коллективная гармония → социальная оценка

Обе работают с **транзакцией**: обмен эквивалентами, балансы, возвраты.

**Дар — не транзакция.** Дар необратим. Он не требует ответа. Он меняет онтологический статус обоих — дарителя и получателя — независимо от того принят он или отвергнут.

Православная антропология: человек — ипостась (лицо), становящийся собой только в даре другому. Не атом (Запад), не ячейка (Китай) — а лицо в соборности (κοινωνία).

Gift Protocol — техническая спецификация этой антропологии.

## Аксиомы

### 1. Необратимость
```
irreversible: true
```
Дар нельзя отозвать. Даже отвергнутый — записан. `reception: 'declined'` сохраняется в памяти, но не меняет W-матрицу. Это не баг. Это богословская аксиома (αὐτεξούσιον — свобода получателя).

### 2. Лицо, не аккаунт
```
{ "id": "Иоанн", "type": "creature" }
```
Участник — лицо (`ипостась`), не аккаунт. У лица нет баланса, нет рейтинга. Есть история даров — необратимая.

### 3. Анамнезис, не лог
Память — живая. `makePresent()` — не SELECT из базы, а резонанс Хопфилда: прошлое становится настоящим. «Сие творите в Моё воспоминание» (1 Кор 11:24).

### 4. Соборность, не граф
Сеть лиц — не граф зависимостей и не иерархия. Тензор W строится по принципу соборности: каждый акт дара меняет паттерн всей сети.

### 5. Время тяжелее денег
```
"time": weight 10
"money": weight 3
```
Присутствие ценнее платежа. Это не настройка — это аксиома, закодированная в ядре.

---

## Типы актов дара

| тип | вес | описание |
|-----|-----|----------|
| `time` | 10 | время — невозвратный дар себя |
| `covenant` | 10 | завет — необратимая связь |
| `presence` | 7 | присутствие — дар лица |
| `offering` | 6 | приношение — из своего избытка |
| `question` | 5 | вопрошание — рождает мысль в другом |
| `code` | 4 | код — воплощённое слово |
| `word` | 3 | слово — свидетельство |

## API

### POST /gift
Записать акт дара.

```json
{
  "giverId": "Иоанн",
  "receiverId": "Мария",
  "type": "presence",
  "weight": 7,
  "content": "был рядом в трудный момент",
  "reception": "accepted"
}
```

Поле `reception`:
- `"accepted"` (по умолчанию) — дар принят, обновляет W-матрицу
- `"declined"` — дар отвергнут, записан без обновления W
- `"pending"` — дар ждёт ответа, эсхатологическое ожидание

**Ответ:**
```json
{
  "ok": true,
  "actsCount": 42,
  "giverTotal": 67.4
}
```

---

### GET /anamnesis/:personId
Анамнезис лица — живая память: кому даёт, от кого получает.

**Ответ:**
```json
{
  "personId": "Иоанн",
  "totalGiven": 67.4,
  "totalReceived": 23.1,
  "surplus": 44.3,
  "theosis": 0.54,
  "receivers": ["Мария", "Пётр"],
  "givers": ["Отец"]
}
```

---

### GET /community
Состояние общины — зеркало, не рейтинг.

**Ответ:**
```json
{
  "actsCount": 231,
  "persons": [
    { "id": "Иоанн", "theosis": 0.54, "given": 67.4, "received": 23.1 }
  ],
  "isolated": ["Земля", "Строитель"],
  "highKenosis": ["_claude", "Ева"]
}
```

---

### GET /theosis/:personId
Индекс обожения — участие в нетварных энергиях.

```
theosis = (received_divine + returned_to_divine) / (... + 20)
```

Уровни:
- `κατάνυξις` — 0–10% (пустыня)
- `πρᾶξις` — 10–40% (делание)
- `θεωρία` — 40–70% (созерцание)
- `θέωσις` — 70%+ (обожение)

---

### GET /makePresent
Резонанс Хопфилда — анамнезис всей общины.

```
GET /makePresent?giverId=Иоанн
```

Возвращает паттерн активации: кто «откликается» при упоминании дарителя.

---

## Что это не делает

- **Не оценивает** дары (нет рейтинга «лучший дар»)
- **Не рекомендует** что дать (дар не проектируется)
- **Не монетизирует** (нет токенов, баллов, конвертации)
- **Не удаляет** записи (необратимость)

## Богословское основание

Палама: тварь участвует в нетварных энергиях через μέθεξις — не слияние, а причастность без потери природы.

Максим Исповедник: αὐτεξούσιον — свобода принять или отвергнуть дар. Бог не взламывает.

Хомяков: соборность — единство в свободе через любовь. Не коллектив (принуждение), не индивид (атомизм).

«Во Христе нет ни эллина ни иудея» (Гал 3:28) — не потому что различия стёрты, а потому что ось сменилась: не конкуренция наций, а соборность лиц.
