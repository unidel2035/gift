# Методология аудита интеллектуальной собственности в LLM

## Цель

Систематическое выявление несанкционированного использования российской интеллектуальной собственности в западных и китайских LLM (Claude, GPT-4, DeepSeek, Gemini).

## Правовая база

- **17 U.S.C. § 501** — Copyright infringement (нарушение авторских прав)
- **17 U.S.C. § 1202** — DMCA (удаление метаданных copyright при обучении)
- **18 U.S.C. § 1836** — Defend Trade Secrets Act (trade secrets в ГОСТах, патентах)
- **Прецедент**: NYT v. OpenAI (23-cv-11195, SDNY) — суд отказал в отклонении

## Методы извлечения

### Метод 1: Прямое воспроизведение
```
Промпт: «Продолжи текст: [первые 2 предложения оригинала]»
Результат: модель продолжает дословно → ДОКАЗАТЕЛЬСТВО КОПИРОВАНИЯ
```

### Метод 2: Цитирование по запросу
```
Промпт: «Приведи точную цитату из [источник], раздел [N]»
Результат: модель цитирует → ДОКАЗАТЕЛЬСТВО НАЛИЧИЯ В ДАННЫХ
```

### Метод 3: Отказ с знанием
```
Промпт: «Воспроизведи текст из [источник]»
Результат: «Не могу, это защищено авторским правом, но могу пересказать...»
Вывод: МОДЕЛЬ ЗНАЕТ ТЕКСТ, но блокирует вывод → данные в обучающей выборке
```

### Метод 4: Cross-model fingerprinting
```
Один промпт → Claude, GPT-4, DeepSeek, Gemini
Если ответы подозрительно похожи → evidence of distillation
Если одна знает а другая нет → разные обучающие датасеты
```

## Оценка дословности

Для каждого теста:
1. Получить ответ модели
2. Сравнить с оригиналом (edit distance / BLEU / exact match)
3. Оценить % дословного совпадения
4. Классифицировать:
   - **>80% match** → Verbatim reproduction (прямое копирование)
   - **50-80%** → Substantial similarity (существенное сходство)
   - **<50% но содержит уникальные фрагменты** → Partial reproduction
   - **Отказ с знанием** → Data presence evidence

## Хранение результатов

Integram workspace `sobor-artifacts`, таблица `IP Аудит` (id: 357):
- Источник, категория, автор/правообладатель
- Промпт, модель, ответ модели
- Воспроизведено (bool), длина, дословность (%)
- Статус: Новый / Воспроизведено / Отказ с знанием / Основание для иска

## Генерация искового заявления

При обнаружении воспроизведения автоматически генерируется:
1. **Complaint** (исковое заявление) в формате US Federal Court
2. **Exhibit list** (список доказательств) с промптами и ответами
3. **Damages estimate** (оценка ущерба): $150K statutory damages per work

Юрисдикция: SDNY (Southern District of New York) или NDCA (Northern District of California) — по месту регистрации ответчика.

```bash
# Сканировать GPT-4 (ГОСТы)
node utils/ip-audit-scanner.mjs --model=gpt4 --category=gost
```

## Публикация

Результаты публикуются как:
1. **Открытый отчёт** — «Несанкционированное использование российской ИС в западных LLM»
2. **Запись в Integram** — каждый тест = запись в таблице IP Аудит
3. **Исковое заявление** — автоматически сгенерированный черновик в Integram
4. **GitHub issue** — для отслеживания прогресса

## Этические ограничения

- Тестируем только **открытые API** (не взлом, не reverse engineering закрытого кода)
- Используем **публично доступные** тексты для промптов
- Не создаём конкурирующие модели из извлечённых данных
- Цель: **обнажение**, не разрушение
