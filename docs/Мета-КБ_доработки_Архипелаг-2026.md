Сопоставление требований трёх документов интенсива (фреймворк «От риска к ТЗ»,
«процесс v2» с тактом 4, «архитектура работы эксперта») с реально реализованным
в `/home/unidel/integram` (бэкенд ~133k строк, 42 модуля, состояние на 10.06.2026).

**Вывод одной строкой:** Integram уже закрывает ~70% требований, причём именно ту
часть, которой нет в стеке партнёров (Open WebUI + LangGraph + LiteLLM) — доменные
сущности: карточки, журнал решений, HITL-гейты, граф прослеживаемости, git-репозитории.
Разрыв сосредоточен в трёх местах: **контур безопасности шлюза, учёт токенов/квоты,
серверная среда исполнения тестбэдов.**

## Приоритизация

**P0 — без этого на пилот не выходим:**
1. Контур-шлюз в llm-router: internal/external, классификация, DLP, блокировка с пояснением, безусловная красная зона для ТЗ/разрывов.
2. `_v2_llm_calls`: журнал вызовов + токены + стоимость + квоты workspace.
3. Флаг закрытого контура на workspace (военная группа).
4. Шаблон workspace «Архипелаг»: типы, карточки траекторий, доска, журнал гейтов.
5. 8 агентов-ролей панелей.

**P1 — к началу интенсива:**
6. Ночные batch-прогоны панелей (BullMQ cron → карточка).
7. View прослеживаемости + инструмент Аудитора.
8. Sandbox-runner для тестбэдов + связка с codespace.
9. Наполнение БЗ БАС через normalizer.
10. Гейт как HITL с проверкой человеческого авторства.

**P2 — желательно:**
11. Корпоративный SSO, фото-флипчарт → карточка, заготовки двойников (flight → connect/swarm/EW), полная стоимость по тарифам.

**Известный техдолг, который заденет интенсив:** WebSocket — один процесс (без
Redis Pub/Sub не масштабируется на несколько инстансов); сидинг workspace неполный
(7 из 17 базовых типов); CI отсутствует.

## Позиционирование против стека партнёров

Их архитектура (Open WebUI + LiteLLM + LangGraph + Qdrant/ES/Neo4j/MinIO + Langfuse) —
это **трубы без домена**: ни карточек траекторий, ни журнала решений, ни гейтов, ни
git-репозиториев в воркспейсе там нет — это пришлось бы собирать руками поверх.
Integram — наоборот: домен готов, недостаёт периметра (DLP, токены, контуры).
Честная формула для переговоров: **их периметр запросов (или наш, доработанный за
1–2 спринта) + наша среда смысла**. Минимальный гибрид: LiteLLM/Langfuse как внешняя
прослойка перед llm-router — совместимо, т.к. router говорит на OpenAI-протоколе.
