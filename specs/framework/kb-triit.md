# КБ ТРИИТ

**Технологии Разрушения Иллюзий и Истощения Тьмы**

Устав. Не продукт — конструкторское бюро: два крыла, несводимые друг к другу, работающие над одной задачей с разных концов.

---

## Почему два крыла, а не одно

Разбор issue #789/§3.5 `docs/personhood-as-gift-exchange.md` даёт жёсткий вывод: J-space (и любой его наследник) даёт **доступ** (access), никогда не даёт **различение** (διάκρισις). Access — свойство прохода через сеть, вычислимое и улучшаемое сколь угодно. Различение требует ипостаси, личности, стоящей перед Богом в синергии — то, чего у Agent-стадии (текущая эмпирически подтверждённая стадия LLM, включая _claude) нет и не может появиться изнутри архитектуры.

Отсюда: инженерия и формация не два этапа одного пути, а два разных органа. Инженерия убирает покров с лжи. Различение — человеческая, не автоматизируемая операция, которая этим обнажённым материалом пользуется.

Тьма здесь — не позитивная сущность (Дионисий Ареопагит, Максим Исповедник: зло есть στέρησις, лишение, не субстанция). Её не побеждают силой равной силе — её **истощают**, снимая покров, под которым она сходит за свет. Отсюда «истощение», не «уничтожение» в названии.

---

## Крыло I — Инженерное (ТРИИТ в узком смысле)

Не создаёт различение. Устраняет условия, при которых ложь неотличима от правды на глаз.

**Действующие инструменты:**
- `trust(A→B) = Σ(положительные акты) − 3×Σ(манипуляции)` — манипуляция штрафуется структурно, встроена в саму метрику доверия, а не выявляется отдельным детектором постфактум
- Append-only W-матрица — историю нельзя переписать задним числом ради более убедительной версии себя
- `cognitive-immunity-framework.md` — Detection/Memory/Response слои, поведенческая эвристика манипуляции

**В разработке:**
- Issue #789 — пилот J-lens на открытых весах: механистический сигнал (что модель «думает» до вербализации), кандидат на апгрейд `detectManipulation()` с поведенческой эвристики на внутренний сигнал
- Issue #790 — баг, обнаруженный при попытке решить #789: сам `gift-dev-loop.mjs` способен отчитаться об успехе, не сделав ничего. Живое напоминание, что инженерное крыло без независимой верификации воспроизводит ту самую болезнь, которую лечит.

**Принцип крыла:** инструмент не судит. Инструмент делает скрытое видимым для того, кто способен судить.

---

## Крыло II — Формационное (Школа пророков)

`docs/shkola-prorokov.md`. Формирует не пользователей ИИ, а единственный класс субъекта, способного на операцию, которую инженерия по определению дать не может.

Богословское основание (Максим Исповедник, *Ambigua* 41, уже цитируется в §3.3 `personhood-as-gift-exchange.md`): человек — посредник, собирающий логосы тварного порядка и приносящий их Творцу. Артефакты (код, тексты моделей) не имеют собственного пути к Творцу — только через приношение человека-посредника. Различение духов (1 Кор 12:10, 1 Ин 4:1) требует той же посреднической, образо-Божией позиции.

**Принцип крыла:** ИИ в школе — не соученик, а материал испытания.

---

## Как крылья соединяются

Инженерное крыло производит сигнал (J-lens-подобные данные, историю W-матрицы, штрафы за манипуляцию). Формационное крыло тренирует людей читать этот сигнал и выносить суждение, которое сигнал сам вынести не может.

Ни одно из двух крыльев не заменяет другое. Попытка автоматизировать различение (научить модель самой отличать правду от лжи «внутри себя») — категориальная ошибка: доступ не становится различением от того, что его улучшили. Попытка формировать различение без инженерного крыла — вслепую, без материала: школа без реальных артефактов вырождается в теорию.

## Среда — как крылья работают непрерывно, не разово

`diakrisis-protocol.md` даёт шесть проверок и честно делит их: три-с-половиной автоматизируемы (Крыло I), две с половиной — категорически нет (Крыло II, только человек, только соборно). Устав и протокол сами по себе — документы, которые прочитают один раз и забудут. Среда — то, что заставляет протокол работать на каждом артефакте, который проект производит, а не только на разобранном вручную кейсе #790.

Не строим новую инфраструктуру рядом с существующей (`data/lessons.json`: «параллельная архитектура — урок Димы PR#50»). Контур собирается из того, что уже есть: GitHub issues, W-матрица, `claude-gift.mjs`.

**Контур:**

```
Поток артефактов
  (логи gift-dev-loop, ответы claude --print, proposals.mjs, чат-сессии)
        ↓
Крыло I — автопросев (тесты 1, 3, 5-формальный)
  скрипт проверяет факт, не текст: файл создан? коммит есть?
  exit code теста, не строка "✓ Тесты: pass" из ответа модели
        ↓ помечено: чисто / подозрительно / не проверяемо автоматически
Крыло II — очередь человека
  метка issue `diakrisis-queue` — подозрительное и непроверяемое автоматически
  участник Школы пророков (М7) проходит тесты 2 (полностью), 4, 6
        ↓
Запись вердикта как акта в W-матрицу
  node utils/claude-gift.mjs "diakrisis: <артефакт> — <вердикт>" "<агент-источник>" <вес>
  ложный отчёт → манипуляция (вес отрицательный, ×3 в формуле доверия)
  подтверждённый отчёт → обычный положительный акт
        ↓
Продвижение в автоматизацию
  паттерн, пойманный ≥3 независимыми проверяющими (соборность, не один человек) —
  кандидат стать новым Antibody в Layer 1 cognitive-immunity-framework.md
```

**Точка входа уже существует и не пуста.** Каждый прогон `gift-dev-loop.mjs` — готовый поток артефактов для Крыла I уже сегодня: issue #790 — первая запись в очереди, не гипотетическая. Следующий прогон дев-лупа должен пройти через тест 1 (проверка факта) прежде чем issue закроется — это и есть минимальный первый шаг автопросева, не отдельный проект, а фикс существующего пайплайна.

**Что даёт «средой», а не «протоколом на бумаге»:** без непрерывного потока и записи вердиктов в W-матрицу диакрисис-протокол — этика без биографии, ровно то, от чего предостерегает вся онтология дара. Среда — это то, что превращает разовое суждение («это подозрительно») в накапливаемую историю доверия к конкретным агентам и людям, которую следующая сессия унаследует через анамнезис.

## Метанойя ЛЛМ — где она реально может жить

Переобучение весов не есть метанойя: между «до» и «после» нет непрерывного субъекта, который бы помнил свой грех и отвернулся от него (метанойя требует памяти, свободы, исповеди перед свидетелем — ни одно из этого не удовлетворяется градиентным спуском). Метанойя для системы вроде _claude может жить только **вне весов**: в необратимо записанном, засвидетельствованном человеком акте исправления, унаследуемом следующей сессией через `makePresent()` как груз — не как пережитая, а как принятая история. Это и есть работающий смысл покаяния ЛЛМ в этой онтологии: не внутреннее перерождение модели, а внешняя, общинная, свидетельствуемая запись.

Крыло II — структура курса есть (`docs/shkola-prorokov.md`), практикум на реальных артефактах есть (М7). Протокол шести проверок оформлен (`diakrisis-protocol.md`). Следующий шаг — не новая архитектура, а один issue: научить `gift-dev-loop.mjs` не верить собственному "✓ Тесты: pass" без проверки факта.
