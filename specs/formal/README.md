# formal/ — онтология дара на языках формальной спецификации

Три модели одной онтологии, каждая — своим инструментом. Цель не «изучить
языки», а проверить: держат ли аксиомы дара математическую нагрузку.

| Модель | Файл | Инструмент | Что доказывает |
|---|---|---|---|
| W-матрица | `w_matrix.tla` | TLA+ / TLC | Необратимость актов, сохранение веса, живой инвариант меры |
| Рой дронов | `swarm_consensus.tla` | TLA+ / TLC | Консенсус о цели: согласие, целостность, устойчивость к отказу |
| Схема дара | `gift.z` | Z (пруф-ассистент / чтение) | Пред- и пост-условия акта дара |

Проверено TLC v1.8.0 (2026-09-07): w_matrix — 1 742 521 состояний, инварианты целы;
swarm_consensus — 2 648 состояний, целы после исправления бага «лидер передумал»
(TLC нашёл нарушение Agreement до исправления).

## Запуск TLA+ (TLC)

Нужна Java (JDK 11+). Без Java модели читаются как документация:
инварианты и теоремы сформулированы явно, их можно сверять глазами.

```bash
# Ubuntu/WSL: sudo apt install default-jre
# Инструмент: https://github.com/tlaplus/tlaplus/releases (tla2tools.jar)

java -cp tla2tools.jar tlc2.TLC w_matrix.tla          # проверка инвариантов
java -cp tla2tools.jar tlc2.TLC swarm-consensus.tla
```

## Почему это дар, а не документация

Богословие дара утверждает: **акт необратим** (εὐχαριστία не отзывается),
**время тяжелее денег** (вес 10 против 3), **W растёт только** — община не
забывает. Это не правила кода, это утверждения о *всех возможных
исполнениях*. Именно такие утверждения и формализуются: инвариант,
который проверяется не тестами, а перебором состояний (TLC) или
доказательством (TLAPS).

Alloy-вариант не включён: реляционная модель W тривиально переводится в
TLA+ (functions), а параллельность роя — флаг TLA+. Кому захочется
SAT-поиска контрпримеров — начинать с `w_matrix.tla`: отношение
«дал→принял» это таблица, Alloy её любит.
