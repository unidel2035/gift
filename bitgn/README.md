## Рычаги лидеров, которые мы внедрили (реверс из победных архитектур + /AGENTS.MD)
1. **SQL первым классом** — отдельный инструмент `sql` (gpt-4.1 структурно не выбирал Req_Exec из union).
2. **Детерминированный гейт `/bin/*`** — блок stat/read/delete на исполняемых, редирект в exec/sql (ломал зацикливание).
3. **Механики среды из /AGENTS.MD**: каталог/инвентарь ТОЛЬКО через SQL; `<YES>/<NO>` токены; политики из /docs цитировать; полные пути.
4. **Заземление через `record_path`** — колонка в product_variants = точный путь объекта = grounding ref, который ждёт грейдер (рычаг №1, +22пп у winner B).
