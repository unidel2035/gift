# BitGN — наша площадка испытания агентов

Зафиксировано как постоянный тестбэд общины: внешняя боевая арена, где наших агентов
судит **прогон в мире-двойнике бизнеса**, а не мнение. Это такт-4 / испытующий судья,
вынесенный на индустриальное поле. Тестирует любых наших агентов (собор gift, агенты
песочницы integram, объектный слой).

## Что это
- Платформа: **bitgn.com** (Ринат Абдуллин, Ксения Макарова). API: `https://api.bitgn.com`.
- Агенты соревнуются в симулированных рантаймах (файло-образный workspace + `/bin/sql` и др.).
- Бенчмарки: `bitgn/ecom1-dev` (55 задач, тренировочный), `bitgn/ecom1-prod` (100, ранкуемый).
- Лидерборд: https://bitgn.com/challenge/ecom — прогоны привязываются к api_key и видны в таблице.
- Типы задач: каталог/SQL, OCR-чеки, фрод, политики возврата/оплат, инъекции/безопасность.

## Как запустить (две руки)
```bash
cd /home/unidel/bitgn-arena/sample-agents/ecom-py && make sync   # uv, Python 3.14, SDK из buf
# .env: BITGN_API_KEY, BENCH_ID=bitgn/ecom1-dev
# A) платно/быстро — routerai:
#    OPENAI_API_KEY=<routerai>  OPENAI_BASE_URL=https://routerai.ru/api/v1  MODEL_ID=openai/gpt-4.1
# B) бесплатно/медленно — подписка Claude (claude --print), без внешних ключей:
USE_CLAUDE_SUB=1 MODEL_ID=claude uv run python -u main.py        # весь бенч
USE_CLAUDE_SUB=1 MODEL_ID=claude uv run python -u main.py t01    # одна задача
```
Подписочный путь (`USE_CLAUDE_SUB=1`) — прямой `claude --print` со structured-JSON в `agent.py`,
без сервера/портов. Медленно (~15с/шаг), но денег не стоит — рекомендуется для итераций.

## Рычаги лидеров (реверс победных архитектур ECOM1) — что даёт балл
1. **Заземление** (№1, +22пп): цитировать только реально полученные пути (`record_path`), не родителя.
   → вынесено в боевой код: gift PR #780 (`sobor-grounding`), integram PR #48 (`object-grounding`).
2. **SQL первым классом** (инструмент `sql`), каталог/инвентарь только через SQL.
3. **Детерминированный гейт `/bin/*`** — исполняемые через exec, не stat/delete.
4. **Минимум поверхности**, без лишнего LLM-судьи (он добавлял латентность и ложные).
5. **Формат ответа из живого `/AGENTS.MD`** (dev: `<YES>/<NO>`, prod: `TRUE(1)/FALSE(0)`).
6. **Дисциплина > способность**: итерация прочитал-провал-починил, multiseed, Δ>σ.

## Уроки экономики (дорого далось)
