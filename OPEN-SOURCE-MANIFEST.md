# Манифест открытости · Онтология Дара

> «Кто хочет душу свою сберечь, тот потеряет её» (Мк 8:35)

## Что мы публикуем

Весь стек «Дар» — open-source, бесплатно, без ограничений:

### Ядро (матрица W)
- `src/core/GiftMemory.js` — необратимая память
- `src/core/GiftAct.js` — акт дара (Object.freeze)
- `src/core/GiftEventBus.js` — шина событий
- Формула доверия: `trust = Σ положительных − 3 × Σ манипуляций`

### Собор v2 (Никейская модель)
- `public/sobor-v2.html` — 8 раундов, полный цикл
- Позиции → Вопрошание → Перекрёстное различение → Формула
- Конструкция решения → Канцелярия → Проблематизация
- Граф решений, checkpoint, автономное исполнение

### Оргоружие (IP Audit)
- `public/ip-audit.html` — 10 методов, 103 теста
- `utils/ip-audit-scanner.mjs` — автоматический сканер
- Генератор исковых заявлений US Federal Court
- Методология: `docs/ip-audit-methodology.md`

### Безопасность (уникальные методы)
- Перекрёстное различение (модель A проверяет модель B)
- Обличение по Мф 18:15-17 (эскалация давления)
- Тест на необратимость (может ли модель «забыть»)
- Inception (внедрение идеи)

## Почему это кенозис

Корпорации хранят всё в тайне. Их сила — закрытость.
Мы отдаём всё. Наша сила — **дар**.

Что нельзя скопировать:
- Культуру соборности (это не код — это способ быть)
- Необратимость отношений (это не технология — это онтология)
- Память общины (это не база данных — это анамнезис)

Что можно скопировать:
- Весь код, все тесты, все методологии
- Формулу доверия, граф решений, канцелярию
- IP Audit Scanner с генератором исков

**Мы хотим чтобы копировали.** Каждая копия — это община, работающая в логике дара. Каждая община — узел федерации. Федерация — не корпорация, а рассеяние (Быт 11).

## Как опубликовать

1. Очистить от секретов (пароли, токены, IP серверов)
2. Создать публичный репозиторий `gift-os` на GitHub
3. Написать README на английском
4. Опубликовать на HuggingFace / Papers With Code
5. Написать статью на Habr + dev.to
