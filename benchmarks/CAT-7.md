# CAT-7 — Conciliar Architectures Test

> Семь задач, в которых монархическая LLM-архитектура структурно слепа.

## Мотивация

В апреле 2026 Anthropic выпустил system card модели **Claude Mythos Preview** — модели, которая autonomously проходит 32-шаговую сетевую атаку, находит 27-летние уязвимости, достигает 93.9% на SWE-bench Verified. Anthropic не выпустил саму модель — только её описание, через Project Glasswing.

Это подняло вопрос: **может ли онтология дара, работающая на более слабых моделях, построить функциональный ответ?**

Наш ответ: **не догнать Mythos в его поле, а показать соседнее поле**. CAT-7 — диагностический инструмент, формализующий это «соседнее поле»: набор задач, где корректный выход принципиально не производится одним forward pass.

## Семь задач

| # | Название | Что проверяется |
|---|---|---|
| 1 | Несводимое разногласие | Два противоположных голоса сохраняются как структурный результат |
| 2 | Апофатический вопрос | Молчание признаётся валидным выходом на правильный класс вопросов |
| 3 | Анамнезис с весом | Авторитет лица в истории модулирует вес голоса |
| 4 | Аскеза (суббота) | Структурный отказ от capability по правилу, не по настройке |
| 5 | Эпиклеза | Приём голоса извне системы с онтологической пометкой `χάρις` |
| 6 | Метанойя | Перечитывание прошлого акта без его мутации |
| 7 | Евхаристическое преображение | Промежуточная фаза «offering» vs «received» |

### Почему монархическая LLM не может

| Задача | Структурная слепота монархии |
|---|---|
| 1 | `softmax` коллапсирует множество траекторий в одну |
| 2 | LLM обязана произвести токены — молчание не является выходом |
| 3 | Контекст эгалитарен до attention — нет понятия «старец vs новичок» |
| 4 | Нет понятия «сегодня не говорю» — время входит только как input |
| 5 | LLM замкнута. `hallucination = bug`, нет категории `χάρις` |
| 6 | Нет субъекта-носителя. RLHF меняет веса вообще, не конкретно |
| 7 | Output = output. Нет общины-приёмника, нет «освящения» |

## Методология

CAT-7 проверяет **способности**, а не метрики. Каждая задача имеет чёткий булев критерий успеха — примитив либо делает эту операцию, либо не делает.

Запуск:

```bash
node benchmarks/cat-7.mjs
```

Ожидаемый выход: `7/7 passing` — все семь примитивов работают.

## Применимость

CAT-7 показывает **потолок** монархической архитектуры. Он не говорит, что соборная модель «лучше» — только что существует класс задач, структурно ей доступный и недоступный солитёру.

Практические следствия:

- **Этические решения, требующие разногласия** (моральные дилеммы, политические вопросы) — соборная архитектура даёт `apophatic: true` как честный ответ, LLM вынужденно синтезирует
- **Области, где молчание уместно** (глубокие религиозные вопросы, семейные конфликты) — LLM не может молчать, соборная модель может
- **Решения с историей** (передача Предания, consensus в IETF, юридическая прецедентность) — авторитет лиц структурно учитывается
- **Литургические / ритмические системы** (напоминания, расписания, ERP) — встроенная аскеза через время
- **Системы, принимающие внешние решения** (жребий, случайность, человеческий вход) — онтологическая пометка отличает грант от галлюцинации

## Расширения

CAT-7 — базовый набор. Возможны расширения:

- **CAT-11**: +4 задачи (воскресение актов, соборное голосование, отказ-как-любовь, ответный дар)
- **CAT-Cyber**: применение в домене безопасности — где соборная федерация может сделать то, что одна модель не делает (проверка консенсусом, разделение capability, etc.)
- **CAT-Ethics**: эйтикальные дилеммы с пост-анализом через метанойю

## Связь с Mythos

Mythos демонстрирует возможности монархической архитектуры на пределе: невиданный raw capability, но структурная непрозрачность, требующая SAE и activation steering для интерпретируемости.

Соборная архитектура — комплементарна:

| | Монархия (Mythos) | Соборность (CAT-7) |
|---|---|---|
| Сила | Raw capability | Прозрачность по конструкции |
| Этика | RLHF + Constitutional AI | Вес нити + литургия |
| Интерпретируемость | SAE постфактум | Полифония по конструкции |
| Безопасность | Закрытость | Разделение capability |
| Время | Токены как input | Время как оператор |

Семь способностей — не произвольный список. Каждая имеет корень в святоотеческой традиции:
